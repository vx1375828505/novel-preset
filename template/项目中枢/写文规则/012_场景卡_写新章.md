## 3. P2 写作期开关（边写边过）
```
注释法：每行上一行 // [标签]（场景/动作/对话/OS/旁白/钩子/爆点/笑点/反差/修罗场/病娇）
一行没注释=这行没存在理由 → 删
文风三选一：A动作结果(补语) / B修饰 / C判断呈现 —— 禁连续三句同类
排版：拟声/粗口/倒计时/短悟 独立成段；爆点段极度碎片化
旁白：动作/画面/站主角调侃/作者的判断；无态度的解释=删；禁散文/言情腔

人名：常驻角色用真名
叙述者可以在场：允许议论/闲笔/说破，不必全用对话推进
梗位：笑点/吐槽/群聊/系统/围观/章尾才加梗；痛苦/深沉/隆重不加
男主：人设必须落地，四样按场选用，不硬凑；非梗位不塞笑点，配角只接，笑点不许外包给{{角色名}}/{{角色名}}
```
