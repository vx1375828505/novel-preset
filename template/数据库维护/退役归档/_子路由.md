# 子路由 · 数据库维护/退役归档

> 本文件夹唯一门牌（{{日期}} 并入原 `_文件夹说明.md`）。上游=项目导引/001_总路由.md → `数据库维护/_子路由.md`；本卡不写流程。
> 作用=**退役文件的实物存放区**（仓库，不是日志）：某个文件被新版取代/作废了就移进这里，不删除。

## 规矩

1. 退役 = **移入本目录 + 文件名加前缀 `_废弃_`**，不直接删除
2. 文件名保留原路径信息，方便回滚，例：`_废弃_{{原文件名}}_旧版_{{日期}}.md`
3. **退役动作本身**记在 `数据库维护/056_变更日志.md`，本目录不写记录表
4. 回滚 = 移回原位、去掉 `_废弃_` 前缀，同时变更日志补一条

## 什么该退役

- 被新版规则取代的旧规则 · 已作废的方案/失败实验稿 · 名字带旧书名/旧结构的过期文档
