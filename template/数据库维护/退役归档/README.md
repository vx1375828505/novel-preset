# 退役归档 · 数据库维护/退役归档

> 本目录是**退役文件的实物存放区**（仓库，不是日志）：某个文件被新版取代或作废了就移进这里，**不删除**。

## 规矩

1. 退役 = 给文件名加前缀 `_废弃_` + 移入本目录，**不直接删除**。
2. 文件名保留原用途信息与日期，方便回滚，例：`_废弃_规则.3f旧版_20261020.md`。
3. 退役动作本身记在 `../056_变更日志.md`，**必须写清退役原因和日期**；本目录不另写记录表。
4. 回滚 = 移回原位、去掉 `_废弃_` 前缀，同时在 `../056_变更日志.md` 补一条。

## 什么该退役

- 被新版规则取代的旧规则
- 已作废的方案 / 失败实验稿
- 名字带旧书名、旧结构的过期文档
- 重复件、无引用的孤儿产物（如多余 zip、`.pyc`）

## 什么不该退役

- 仍被活跃文件引用的内容（先改引用，再退役）
- 正文与唯一事实源（改动走变更日志，不进本目录）
