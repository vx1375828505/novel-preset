# 03_度量

## 四个指标

| # | 指标 | 怎么算 | 健康区间 | 说明 |
|---|---|---|---|---|
| 1 | 新增文件数 / 周 | 本周新建 md 数 | ≤ 5 | 暴涨说明在失控地"生产文档"而不是干活 |
| 2 | 孤儿文件数 | 没有任何文件引用的活跃文件 | 0 | 只增不减 = 在囤积 |
| 3 | 死链条数 | 引用了不存在路径的条目 | 0 | 改名/删除后的残留 |
| 4 | 平均检索跳数 | 从入口找到目标要经过几次点击 | ≤ 3 | 1 导航 → 2 目录 → 3 文件 |

## 怎么填

1. `rg --files . | wc -l` 得文件总数（排除 草稿/归档备份）
2. `rg -n '00_项目导航' .` 之类的旧串扫描得死链
3. 孤儿靠人工抽查目录下没人引用的文件
4. 检索跳数按"全局记忆 → 项目目录 → 目标文件"数一次

> 指标不是 KPI，**超标不要补数字，要停下来看为什么变多。**
