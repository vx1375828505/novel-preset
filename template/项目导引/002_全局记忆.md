# 00_全局记忆

## 一、四条铁律

1. **所有决定都要跟用户确认** — 不做未经确认的决定。
2. **不擅自做主** — 涉及操作、方案选择等，先征得用户同意。
3. **每次回复后面带推荐方案选项** — 给出建议的同时附上可选项供用户挑选。
4. **重复确认用户表达的意思再动手** — 复述理解，确认无误后再执行。
   - 校准（✅2026-11-08）：用户下「开工/了解项目/继续」类指令时，先按 `001_总路由.md` 派工进夹取文，再读 `项目中枢/006_进度.md` 直接执行；需要拍板的是**改动方案与验收结论**，不是"要不要开始"。
   - 校准（✅2026-11-12）：动正文时，「继续／按建议改」＝**本轮已报范围**授权；改剧情、扩范围、换方案，仍需重新点头。
   - 校准（✅2026-11-12）：用户说「精修文章／写文章」＝**先出报告单**（体检＋逐处清单，原文→改法→理由），等用户逐条拍板；报告单未被点名确认前，正文、规则、设定一律不动。禁把“开始修”当“直接改”。
