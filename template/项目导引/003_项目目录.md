## 三、命名规范

> 模板阶段编号允许空缺：删掉的编号不复用，新建文件用下一个空号或按需重排并全库同步引用。

| 对象 | 规则 | 例 |
|---|---|---|
| 顶层目录 | `NN_名称`，两位序号 | `数据库维护` |
| 普通文件 | `NNN_名称.md`，NNN=全库连续序号（001 起） | `005_项目核心.md` |
| 带版本规则 | `NNN_规则.Nx（中文说明）.md` | `015_规则.3i（排版规范）.md` |
| 正文 | `第NNN章：标题.txt`，三位补零、全角冒号 | `第001章：{{章标题}}.txt` |
| 日期后缀 | `_YYYYMMDD` 结尾 | `{{文件名}}_{{日期}}.md` |
| 子路由（每文件夹一份） | `000__子路由.md`，列清本夹每个文件作用 | `项目中枢/000__子路由.md` |
| 废弃 | 文件名前缀 `_废弃_`，移入 `数据库维护/退役归档/` | `_废弃_旧方案_{{日期}}.md` |
| 备份 | 放 `草稿/归档备份/`，目录名带原因 + 日期 | `{{备份原因}}_{{日期}}/` |

## 四、文件卡规范

每份活跃文件开头必须有【文件卡】，四项：**作用 / 何时用 / 上游 / 下游**（可加"不做的事""不够细看"）。

> 文件名前缀 `NNN_` = 全库连续序号；文件卡里的旧 `【序号】` 保留作历史引用，不再作为查找主入口。找文件看文件名或 `000__子路由.md`。

- 卡片只写**直接邻居**，不写全局关系
- 新建文件必须带卡
- 文件夹配 `000__子路由.md`（每夹唯一门牌：就地列清每个文件作用；原 `_文件夹说明.md` 已并入并退休）
- 增删移文件后三同步：**本文件 + `项目中枢/006_进度.md` + 对方文件卡**（涉剧情再加 `剧情记忆`），改完 `rg` 验旧串零残留
