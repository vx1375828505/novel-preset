## 二、卷纲/细纲格式规范（✅2026-11-14 用户定，全库唯一）

**卷纲（每卷一个文件）** = 一句话概括剧情，粒度到"几章到几章"，按段列：

```
第一段 卷纲：{{角色名}}段·灵气初现——男主暴富躺平→{{角色名}}降临接管→龙国发现异常（第N章-023）
```

**细纲/章纲（每段一个文件）** = 章章过；每章按「场景一／场景二／场景三……」切：

```
## 第N章：档案
场景一（庄园门房｜温宁/陈伯/使团）：温宁按预约制把七拨使团逐批打太极——立她"资产大管家"人设｜推"使团排队"常态
场景二（客厅｜{{男主名}}/五女/温宁）：114页台账摊牌→收为第六徒——功能：新人物入伙+身份升级
需要交代的事：①温宁台账=114页 ②她放弃"不进私人空间"旧规（她本人作废）
剧情推动：庄园从"五女修罗场"变"六人结构"；使团线转暗（第N章起交织）
章尾钩：第八拨使团夜至
```

**铁律**：单场景只推动一件事；场景间架桥（上一场的果=下一场的因）；章尾钩只许一个主钩；定稿才写进本目录文件，草案一律带"草案/待审"字样，用户审核过才转正。
