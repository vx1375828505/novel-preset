# 061_规则调用路由

> 核心：**一轮一规则。路由只负责选，专项规则单独执行。**

## 一、每轮启动

1. 复述本轮任务对象与用户指定目标。
2. 用户已点名规则：直接选对应文件。
3. 用户未点名规则：按本轮唯一主问题，从下方索引选一份。
4. 同时出现多个问题：列出轮次建议，经用户确认后逐轮执行；不得在一轮内合并处理。
5. 本轮只读取、执行选中的专项规则。其他文件里的指针只用于定位，不展开执行。

## 三、一轮边界

- 选中文件后，只完成该文件对应的检查或修改。
- 发现其他问题：只记入“后续轮次”，不得顺手执行另一份规则。
- 需要另一份规则才能继续：本轮停下，说明原因与下一份建议文件。
- 用户明确要求连续施工：仍按“一轮一份”拆分，不把连续施工理解为一轮多规则。
- 素材库、桥段库、判例库不是专项规则，不得代替规则执行。
- 本路由是导航，不与任何专项规则共同组成一轮任务。

## 四、冲突与未完成处理

1. 用户最新拍板优先。
2. 两份规则内容冲突：记录冲突，停止相关改动，交用户裁决；不靠多读几份自行裁决。
3. 任务无法由一份规则独立完成：先交未完成项与下一轮建议，不擅自扩类。
4. 每轮结束只留三项记录：**本轮执行文件／本轮结果／未执行的后续项**。

## 五、编号口径

- `061—083` 是文件序号与建议使用次序，不是优先级，也不是固定全链。
- 不要求从062开始逐份跑完；按任务选一份即可。
- 082验收与083交付同样各自独立，不自动附在其他专项任务后。
