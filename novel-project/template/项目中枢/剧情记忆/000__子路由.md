```

020_人物状态总表.md ← 女主+男主当前状态，跨卷追溯唯一依据。体积硬顶 15KB。
_卷N归档/       ← 卷收口时流水压成 ≤100 行存档，此后路由永不经过（除非用户点名考古）。
```

**操作规则**：写新章/精修 → 只读 `019_当前卷.md` 相关段（单轮默认不开其余）；跨卷查状态 → `020_人物状态总表.md`；考古 → 用户点名才开 `_卷N归档/`；**卷收口（三个检查点）** → 流水压缩迁移 + 总表核对 + 路由刷新。
**体积红线**：任一文触顶未处理 → 记入 `006_进度.md` 待办，禁堆着不管。
