# 00_约束

## 约束一｜唯一事实源（一个事实只有一个家）

同一个事实**只能有一个权威位置**，其他地方一律**引用，不复制**。复制即分裂，分裂即打架。

| 事实 | 唯一权威 | 其他位置怎么写 |
|---|---|---|
| 交互纪律 | `项目导引/002_全局记忆.md` | App 层 `/var/minis/memory/GLOBAL.md` 是**副本**，改动须两边同步 |
| 路由（派工） | `项目导引/001_总路由.md` | 各文件夹 `000__子路由.md` 就地指路；其他文件只说"见总路由" |
| 目录 / 命名 / 文件卡规范 | `项目导引/003_项目目录.md` | 不在别处另写一份目录树 |
| 进度 / 断点 / 冻结项 | `项目中枢/006_进度.md` | 其他文件只引用，不抄进度 |
| 剧情现在时 | `项目中枢/剧情记忆/019_当前卷.md` | 支线/章节摘要不重复叙述 |
| 设定最高判据 | `项目中枢/005_项目核心.md`（T0-T4） | 人物卡是它的展开，冲突以 T0 为准 |
| 写法规则 | `项目中枢/写文规则/` + `文章精修规则/` | 场景卡是入口，细则不复制 |
| 库结构变更记录 | `数据库维护/056_变更日志.md` | 不进 `006_进度.md` |

**判定动作**：当你想在 B 文件里再写一遍 A 文件已有的内容 → **停手，改成一句引用**。

## 约束二｜引用完整性

- 所有路径引用用**相对项目根的路径**，不用绝对路径
- **改名 / 移动 / 删除之后，必须 `rg` 扫旧串**，确认零残留；有残留就在同一次操作里改掉
- 每条引用必须指向**当前存在**的文件或目录
- 引用失效未修的，记入 `056_变更日志.md` 的"待修"项，下一次体检必须清掉

## 约束三｜命名规范

完整规则见 `项目导引/003_项目目录.md` 第三节。此处只放三条红线：

1. 顶层目录必须 `NN_名称`，序号不跳号
2. 正文必须 `第NNN章：标题.txt`（三位补零、全角冒号）
3. 废弃文件必须前缀 `_废弃_`，并移入 `退役归档/`

## 约束四｜写权限

| 谁 | 能做什么 |
|---|---|
| **用户** | 唯一拍板人。任何结构变更、规则变更、正文改动，都要用户点头 |
| **AI** | 只能：①提议方案 ②执行已拍板的动作 ③执行后如实记账 |
| **AI 禁止** | 未经拍板动文件；把"删一个文件"扩大成"连带清理"；凭记忆写剧情（必须先查正文） |

**结构变更的前置动作**：先出**改动清单**（要动哪些文件、怎么动、备份在哪），用户回复后才执行。

## 违规处置

| 情况 | 处置 |
|---|---|
| 违反唯一事实源 | 保留权威那份，另一份改为引用；记入变更日志 |
| 引用断裂 | 当次操作内修掉；修不掉记"待修"，下次体检必清 |
| 未经拍板动文件 | 立即停止，列出实际改动清单交用户裁定，不自行回滚 |
| 凭记忆写剧情 | 作废重来，先读 `正文` 对应章 |
