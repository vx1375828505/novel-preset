## 二、卷纲/细纲格式规范（✅用户定，全库唯一）

**卷纲（每卷一个文件）** = 一句话概括剧情，粒度到"几章到几章"，按段列：

```
第一段 卷纲：{{角色名}}段·{{阶段名}}——{{开局}}→{{接管}}→{{外部事件}}（第{{N}}章-第{{N}}章）
```

**细纲/章纲（每段一个文件）** = 章章过；每章按「场景一／场景二／场景三……」切：

```
## 第{{N}}章：{{章标题}}
场景一（{{地点}}｜{{出场人物}}）：{{事件}}——立{{人设}}｜推{{常态}}
场景二（{{地点}}｜{{出场人物}}）：{{冲突摊牌}}→{{结构变化}}——功能：{{新人物入伙+身份升级}}
需要交代的事：①{{待交代一}} ②{{待交代二}}
剧情推动：{{结构变化}}；{{线}}转暗（第{{N}}章起交织）
章尾钩：{{一个主钩}}
```

**铁律**：单场景只推动一件事；场景间架桥（上一场的果=下一场的因）；章尾钩只许一个主钩；定稿才写进本目录文件，草案一律带"草案/待审"字样，用户审核过才转正。
